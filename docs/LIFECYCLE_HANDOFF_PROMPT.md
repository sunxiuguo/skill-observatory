# 后续维护交接 prompt

此入口只触发项目唯一合同，不复制步骤、状态或历史授权。将下面的具体任务替换为本轮需求：

```text
维护当前 Skill Observatory 项目，完成【具体任务及预期结果】。先读根 AGENTS.md、docs/PROJECT_CONTRACT.md 与 docs/STATUS.md，核对当前 diff、配置及证据，按合同的目标、owner、权限和验收路由持续实施到可验收结果。既有局部交付不代表真实 Skill/用户/递归改善已完成。按根入口已记录的用户授权自动提交/推送本项目 origin/main，核对远端和最终 CI；未经匹配授权不部署、付费、修改全局权限或对外发送。
```

跨执行者或关键状态可能丢失时，另附本轮目标、已验证结果、当前状态、下一步、证据路径和风险；原始证据保留私有，真实状态更新 STATUS。
